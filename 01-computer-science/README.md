# 01 Computer Science

计算机基础部分聚焦面试中最常见的底层知识，包括操作系统、计算机网络、数据结构以及常用正则表达式备忘。

## 子目录

- `os/`：操作系统基础
- `network/`：计算机网络、HTTP、Socket、TCP
- `data-structures/`：数据结构与基础题型

## 面试前 30 分钟速看

- 先把操作系统里的进程、线程、调度和内存管理串成一条完整主线，方便回答“系统为什么这样设计”。
- 网络部分至少要能顺着 TCP 建连、HTTP 请求和 Socket 通信讲完一次完整调用路径。
- 如果时间不够，优先复述一个数据结构或无锁队列的使用场景，比只背定义更像真实面试回答。
