# 02 Java

Java 主题按内容拆分为以下几个子目录：

- `basics/`：基础语法、面向对象、常见语法与日常开发片段
- `collections/`：集合框架与常见容器问题
- `concurrency/`：并发、多线程、线程池
- `jvm/`：JVM、内存模型、GC、诊断工具
- `io/`：IO、文件与流
- `new-features/`：Java 8/14 等新特性

## 推荐入口

- [并发编程](./concurrency/Java 并发.md)

## 面试前 30 分钟速看

- 复习时优先按“基础语法 -> 集合容器 -> 并发 -> JVM -> IO”顺着讲，比零散背题更容易形成回答链路。
- 高频问法至少要准备 HashMap、ConcurrentHashMap、线程池和 JVM 内存区域这几组核心问题。
- 如果被追问排障思路，尽量把 GC、内存模型和常见日志/工具放到同一个回答里解释。
