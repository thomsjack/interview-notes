## 面试前 30 分钟速看

- 先把关系型数据库、缓存和文档数据库的适用场景分开讲，回答时会更有层次。
- SQL、索引和事务通常是一组连续追问，最好能从查询执行、锁和一致性一路讲到性能优化。
- 如果岗位偏后端，记得准备一个“Redis 为什么不直接替代 MySQL”或“MongoDB 适合什么场景”的对比回答。
