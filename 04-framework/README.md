## 面试前 30 分钟速看

- 优先把 Spring 核心容器、Spring MVC 请求链路和 MyBatis 执行流程区分开来回答，层次会更清楚。
- 如果面试官从 Spring 追问到微服务，最好能自然切换到配置中心、服务注册发现和调用链治理。
- 框架题常常会落到“为什么这么设计”，准备一个 Bean 生命周期或 MVC 分层的完整解释很有帮助。
