# Spring Cloud

这个目录主要收纳 Spring Cloud Alibaba 相关笔记，适合作为微服务、注册发现、配置中心和限流降级的专题入口。

## 当前整理方向

- 当前目录的历史内容已经被压缩到这份总览页，适合先建立整体认知。
- 后续如果继续拆专题，优先按 `注册发现 / 配置中心 / 限流降级 / 消息驱动 / 分布式事务` 维度补齐独立文档。

## 推荐入口

- 先从 Spring Cloud Alibaba 的整体定位入手，明确它解决的是微服务注册发现、配置治理、消息通信和流量控制问题。
- 再按 `Nacos -> Sentinel -> RocketMQ -> Seata` 的顺序梳理常见组件，把配置中心、限流降级、消息驱动和分布式事务串成一条链路。
- 如果你在面试里需要讲落地经验，优先准备“服务注册 + 配置管理 + 流量治理 + 最终一致性”的完整业务路径。

## 复习提示

- 先梳理 Spring Cloud Alibaba 的整体定位，再分别看注册发现、配置管理、消息驱动和流量治理。
- 面试中经常会把 Sentinel、Nacos、RocketMQ、Seata 串在同一条微服务治理链路里追问，建议一起记忆。

## 快速复习

- 第一轮复习重点放在“每个组件解决什么问题”，避免一开始就陷入配置细节。
- 第二轮把 Nacos、Sentinel、RocketMQ、Seata 分别对应到“注册发现、限流降级、异步解耦、分布式事务”。
- 最后一轮尝试用一个订单或交易场景，把服务拆分、配置推送、流量保护和事务补偿连贯讲出来。
