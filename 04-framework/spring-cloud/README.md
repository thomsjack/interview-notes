# Spring Cloud

这个目录主要收纳 Spring Cloud Alibaba 相关笔记，适合作为微服务、注册发现、配置中心和限流降级的专题入口。

## 当前整理方向

- 当前目录的历史内容已经被压缩到这份总览页，适合先建立整体认知。
- 后续如果继续拆专题，优先按 `注册发现 / 配置中心 / 限流降级 / 消息驱动 / 分布式事务` 维度补齐独立文档。

## 复习提示

- 先梳理 Spring Cloud Alibaba 的整体定位，再分别看注册发现、配置管理、消息驱动和流量治理。
- 面试中经常会把 Sentinel、Nacos、RocketMQ、Seata 串在同一条微服务治理链路里追问，建议一起记忆。
