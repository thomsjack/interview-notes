# 05 System Design

系统设计相关内容按主题拆分为：

- `distributed/`：分布式、集群、ZooKeeper、一致性哈希
- `mq/`：消息模型、消息队列、RabbitMQ
- `security/`：安全机制与攻击技术

## 面试前 30 分钟速看

- 系统设计题回答时，优先按“场景目标 -> 核心瓶颈 -> 拆分方案 -> 风险控制”来组织语言。
- 分布式和消息队列经常会一起出现，最好能把一致性、幂等、重试和削峰串成一个回答框架。
- 如果被问到安全，至少准备鉴权、限流、攻击面和日志审计这几个常见落点。
