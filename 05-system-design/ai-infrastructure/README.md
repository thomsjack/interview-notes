# AI 基础设施与智能体系统设计 (AI Infrastructure & Agent Systems)

本专栏聚焦 AI 时代的大规模分布式系统设计、大模型推理算力架构与生产级智能体运行时，帮助架构师与高级工程师系统掌握前沿 AI 系统底层原理：

- [大模型高并发推理服务架构设计](./大模型推理服务与算力架构.md)：深入拆解 PagedAttention 虚拟显存分页、连续批处理 (Continuous Batching)、投机采样 (Speculative Decoding) 与 PD 分离架构。
- [现代智能体运行时与持久化执行架构](./现代智能体运行时与持久化状态架构.md)：全面解析 模型上下文协议 (MCP)、长程任务持久化自愈 (Durable Execution) 与事务性状态回滚机制。
