# Distributed Systems

这一层集中放分布式系统基础、ZooKeeper、集群、一致性哈希和分布式锁相关内容，适合作为系统设计面试中的中高频专题入口。

## 复习提示

- 先把“为什么需要分布式、集群和一致性哈希”讲顺，再进入 ZooKeeper 和分布式锁的实现细节。
- ZooKeeper 相关内容建议按“概念 -> 数据模型 -> 命令行 -> 集群与选举 -> Java API”顺序推进。

## 快速复习

- 第一轮先讲 [分布式](./分布式.md)、[集群](./集群.md) 和 [哈希算法、哈希碰撞、一致性哈希](./哈希算法、哈希碰撞、一致性哈希.md)，把架构动机和路由策略讲顺。
- 第二轮再进入 ZooKeeper 主线，用 [分布式系统概念与 ZK 简介](./1.分布式系统概念与ZK简介.md) 到 [ZooKeeper 基本数据模型](./3.ZooKeeper基本数据模型.md) 建立概念框架。
- 最后一轮重点准备 [分布式锁](./9.分布式锁.md) 这类高频追问，并能解释它和 ZooKeeper/一致性问题之间的联系。
