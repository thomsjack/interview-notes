## 面试前 30 分钟速看

- 复习设计模式时，优先按创建型、结构型、行为型三类去归纳，比逐个背名字更容易回答迁移问题。
- 如果面试官追问真实场景，最好把单例、观察者和适配器分别对应到一个你能说清的业务例子。
- 重构题通常会和面向对象原则一起出现，准备一组“坏味道 -> 改法 -> 收益”的回答会更稳。
