## 面试前 30 分钟速看

- 刷题复习时，优先按“题型识别 -> 常用解法 -> 复杂度权衡”来组织答案，不要只背最终代码。
- 动态规划、链表树、排序和双指针通常是最常见的组合追问，最好每类都能快速举一题说明思路。
- 如果时间有限，至少把一题 LeetCode、一题剑指 Offer 和一组排序算法比较讲顺。
