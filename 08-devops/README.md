# 08 DevOps

运维与工程化工具集中在这一层：

- `docker/`：Docker 安装与访问控制
- `linux/`：Linux 基础、Shell 与日常操作
- `git/`：Git 基础、分支、标签、远程仓库
- `maven/`：构建工具与依赖管理
- `idea/`：IntelliJ IDEA 使用技巧

## 推荐入口

- [Docker](./docker/Centos 安装Docker.md)
- [Linux](./linux/README.md)
- [Git](./git/README.md)
- [Maven](./maven/构建工具.md)
- [IDEA 使用技巧](./idea/IntelliJ IDEA使用技巧.md)

## 面试前 30 分钟速看

- 运维与工程化题目通常从 Linux 命令、Git 协作、Docker 容器和 Maven 构建四条线展开，复习时先抓主线。
- 如果岗位偏后端开发，至少准备一个“本地开发到部署上线”的完整工程化流程回答。
- 遇到排障题时，尽量把日志、构建、容器和系统命令放到同一个排查路径里说明。
