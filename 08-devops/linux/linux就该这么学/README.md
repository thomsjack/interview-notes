# linux 就该这么学

这个子目录更像一组按天整理的 Linux 课程笔记，适合在系统基础之外，作为“命令行与运维入门”的补充学习材料。

## 推荐入口

- [day03](./day03.md)
- [day04](./day04.md)
- [day05](./day05.md)
- [day07](./day07.md)
- [day09](./day09.md)

## 复习提示

- 这组笔记更适合按课程顺序连贯阅读，而不是像 FAQ 一样按关键字跳读。
- 如果你是为了面试复习，建议先完成上一级 `Linux` 总览，再把这组课程笔记当作补充材料查漏补缺。

## 快速复习

- 第一遍直接按 `day03 -> day04 -> day05 -> day07 -> day09` 的顺序读，先建立课程式学习路径。
- 第二遍只摘出和命令行、系统管理、运维入门最相关的内容，把它们转成可口述的知识点。
- 如果时间紧，这组材料不要替代 Linux 主线复习，而是作为上一级总览页后的补充回看。
